# Full product review checklist

Work the list in order. Every finding in the report traces to a checked box.

## Coverage

- [ ] Whole codebase read end to end
- [ ] Every tab and screen opened in the built app
- [ ] Screenshot taken of every tab and screen, and looked at
- [ ] Slow paths timed with real measurements
- [ ] Suspected defects probed live in the running app

## Report

- [ ] Strengths named, each with its evidence
- [ ] Weaknesses named, each with file and line
- [ ] Gaps named, including what is missing outright
- [ ] Improvements ranked (tiers or P0 to P4 phased plan)
- [ ] Task list written for the ranked improvements
- [ ] Avoid list written for ideas that break the hardware limits or the hard $0 rule
- [ ] Could-not-verify items flagged, never dressed up as findings

## Close

- [ ] Headlines and ranked list delivered in chat
- [ ] Full report written to a file
- [ ] No code changed
