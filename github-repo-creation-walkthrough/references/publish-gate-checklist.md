# Publish gate checklist

Use this checklist when a project is ready to publish on GitHub. Work the owner-only items first, then the agent items, and report each item as done or still open. Do not call a project published until every item is done.

## Owner only

- [ ] Flip the repo from Private to Public at launch time (quick toggle, only the owner can do it).
- [ ] Pick the license (a separate owner decision, asked before the agent adds the LICENSE file).
- [ ] Confirm the Meta Muse AI app has access to the repo (add the repo, or switch the app to All repositories).

## Agent

- [ ] Verify the repo exists live on GitHub, is readable, and note its visibility and whether it is empty.
- [ ] Replace any placeholder README with the real README.
- [ ] Add the LICENSE file with the license the owner picked.
- [ ] Create the Release with the zip attached, and verify the asset name and size.
- [ ] Fill in the About description and topics.

## Discrepancies to note when found

- Repo is private instead of public.
- Repo name has different capitalization than agreed.
- A placeholder README exists, meaning a creation checkbox was left on.
