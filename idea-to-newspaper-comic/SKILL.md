# S45 — Idea to newspaper comic strip

## When to use

- Use it when the user wants an idea, a feeling, or a headline turned into a classic 3–4 panel newspaper comic.

- Use it for any concept, including abstract ones; the method portrays them visually instead of labelling them.

- Do not use it for a single illustration; the strip's setup-gag-punchline shape is the point.

## Build the strip in three beats

- Panel 1 is the setup: establish the scene and the situation in one image.

- The middle panel or panels carry the visual gag: the situation turns, shown, not told.

- The last panel is the punchline: the payoff lands visually.

- Keep the strip to 3–4 panels; a longer strip is a different format.

- Write the strip up in the [comic script](templates/comic-script.md): the idea, then one visual per panel.

## The user's words are notes to draw from, never text for the art

- Treat the user's words as notes about what to draw, never as text to put in the drawing.

- No labels in the art, no speech in the art, no captions explaining the joke.

- If the strip needs words to make sense, the drawing has failed; redraw it, do not add text.

## Portray abstract concepts visually, never labelled

- An abstract concept must be shown as a scene, an object, or an action — never as a word in the frame.

- Find the visual metaphor first: what does this concept look like when it happens to someone?

- Test each panel by asking whether a reader who cannot read the user's notes would still get the joke.

## A new image means generate from scratch

- When the user asks for a new image, generate it from scratch; do not edit the old one.

- An edit carries the old image's mistakes forward; a fresh generation starts clean.

- Keep the script and the panel beats; change the drawing, not the structure, unless the user names a structure change.

## Revise by the one named thing

- When the user names one problem, fix that one thing and keep the rest of the strip.

- When the user rejects a strip without naming what is wrong, ask what specifically is wrong before redrawing.

- Record the user's corrections in the script so the next generation keeps them.

## Standing rules

- The user's words are the brief, not the artwork; nothing they said goes into the frame as text.

- Hard $0: use only free generation routes.

- Never claim more than was checked; a script is a plan, and the strip is only proven when the user sees it.

## Where this comes from

- Proven in the Create newspaper comic from ideas thread: one strip through several revision rounds, with the hard rules (no text in the art, fresh generation over edits, visual portrayal of abstract concepts) learned in-thread — recorded in the BNB audit as S45.
