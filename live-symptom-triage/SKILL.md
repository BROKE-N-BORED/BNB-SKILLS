# S47 — Live symptom triage with timed vitals recheck

**Caveat: guarded playbook only — escalate, don't diagnose; NEVER a diagnostic tool.**

## When to use

- Use this skill when the user reports a suspected supplement or drug reaction in real time and needs monitoring and escalation guidance right now.

- Use it only as a guarded playbook. It helps the user watch their symptoms and get help fast. It never diagnoses a condition or decides what is wrong.

## State the escalation lines first

- Give the hard escalation lines up front, before anything else.

- Send the user to 911 or Poison Control at 1-800-222-1222 if their heart rate is over 120 while sitting, if they have sharp pain, or if they vomit blood.

- Offer webPOISONCONTROL as a private text route when the user cannot make a call.

- Repeat the escalation lines whenever a reading crosses a threshold or symptoms get worse.

## Identify the substance

- Ask for a photo of the label and read the substance name and dose off it.

- Ask what else the user took and when, including food, drink, and anything else ingested.

- Check the interactions between the substance and the other things taken, such as coffee plus dabs on an empty stomach.

- Ask when the user took each thing so the timeline is clear.

## Teach the pulse check and set the recheck cadence

- Teach a 30-second pulse count and ask the user to double the count for beats per minute.

- Set a timed recheck cadence of about 15 minutes and keep to it.

- Record each reading with its time so the trend is visible.

- Compare each new reading against the escalation lines and act on any crossing at once.

## Keep the exchange short and easy

- Ask one question at a time.

- Accept one-word answers without pressing for more detail.

- Keep replies short. A person in a reaction cannot read long messages.

## Write a summary the user can show someone else

- Write a one-paragraph summary the user can show a third party, such as a medic or a housemate.

- Include the substance and dose, the time taken, the other things taken, the symptoms, the pulse readings with times, and whether any escalation line was crossed.

- Keep the summary to facts the user reported and readings the user took. Do not add a diagnosis.

## Alternatives for better results

- Offer the webPOISONCONTROL text route when the user cannot or will not call.

- Offer to write the summary early, before the user needs it, so it is ready to show.
