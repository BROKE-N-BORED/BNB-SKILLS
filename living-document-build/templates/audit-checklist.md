# Audit checklist — living document

Use one checklist per audit pass. Record findings in the document's own
audit log or in the section the finding belongs to.

## Consistency audit

- [ ] Read every numbered section in order.
- [ ] List contradictions with both section numbers (numbers, names, procedures, rules).
- [ ] Fix each contradiction in the document.
- [ ] Re-read fixed sections to confirm no new contradiction was introduced.

## Gap audit

- [ ] Read every numbered section looking only for missing content.
- [ ] List gaps with the section each belongs in (skipped steps, assumed gear, unanswered questions).
- [ ] Fill each gap in the document, or mark it as an open question — never guess.

## "Live the guide" scenario-simulation audit

Scenarios (adapt to the document's subject):

- [ ] Ordinary day, hour by hour.
- [ ] One hard week, day by day.
- [ ] One worst-case event, hour by hour.

For each scenario hour:

- [ ] Trace every procedure the scenario calls for.
- [ ] Note gear, supplies, or steps the procedure silently assumes but the document never names.
- [ ] Fold each finding back into the document as a fix, a new section, or a named open question.
