# S27 — Social account setup kit

Set up a project's social accounts with a paste-ready kit per platform, walking the user through one platform at a time with exact in-app steps.

## When to use

- A project launches and needs accounts on TikTok, X, Facebook, YouTube, Instagram, or Linktree.

## Verify the download link first

- Check the download link is live before you build anything, because every bio, post, and pinned comment in the kit points to it.

- Report the check result, and fix the link before the kit goes out when the check fails.

- Build the kit only from assets that are ready to post, using the good video cuts and never the rejected ones.

## Build a paste-ready kit per platform

- Build the kit with the [setup kit template](references/setup-kit-template.md), giving each platform its own section.

- Give each platform its name, bio, first posts, and pinned comments, written paste-ready so the user can copy them straight into the app.

- Name which video files to post on each platform, listing the good cuts by filename.

- Use the user's own words for bios and taglines, plus plain facts, and invent no claims about the product.

## Walk through one platform at a time

- Walk the user through ONE platform at a time, with exact in-app steps, and finish that platform before starting the next.

- Give each step as one short action, because the user follows the steps on a phone.

- Check the platform's gating rules before you promise anything on it, such as TikTok hiding the Links field under 1,000 followers or without a Verified Business Account.

- Supply the workaround when a feature is gated, such as putting the download link as a bio line plus a pinned download comment on every video, and say plainly that it is a workaround.

- Confirm each platform is set up before moving on, and keep a list of which platforms are done and which are still open.

## Where this comes from

- From the CODE FORGE SOCIAL MEDIA MGMT thread (1fd34d86) — download link verified live first, paste-ready kit for six platforms, one platform at a time starting with TikTok, with the 1,000-follower Links-field gate and its workaround. Recorded in the BNB audit as S27.

## Alternatives for better results

- Offer to draft the first week of posts for a platform once its account is live, instead of stopping at the setup kit.

- Ask the user which platform to start with when they have no preference, instead of picking one for them.
